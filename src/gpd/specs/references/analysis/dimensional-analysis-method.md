# dimensional-analysis

Track term dimensions using the authoritative unit system, including derivatives,
integration measures, delta functions and normalization factors. Transcendental
function arguments must be dimensionless. Natural-unit equalities can hide
independent SI dimensions: restore constants where needed to test a disputed
factor. Identify every equation in the requested audit scope; locate anomalies
at file/equation/term level, distinguish convention dependence from a mismatch.
Dimensional agreement is necessary, not proof of a numerical coefficient or
physical model. Retain an assignments table when it makes the audit checkable.
